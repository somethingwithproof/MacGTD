**MacGTD jẹ́ àkójọpọ̀ àwọn ìṣàn-iṣẹ́ macOS fún gbígba àwọn iṣẹ́ sílẹ̀, ṣíṣètò àwọn ìránnilétí, àti ṣíṣe àwọn ìgbà ìfojúsùn oníwọ̀n-àkókò pẹ̀lú àwọn àpù tí o ti ń lò tẹ́lẹ̀.**

A kọ́ ọ yípo [Getting Things Done](https://gettingthingsdone.com/), ó sì ń mú gbígba iṣẹ́ nípasẹ̀ àpótí ìfọ̀rọ̀wérọ̀, pátákó ìdáàkọ, àti ìgbàsílẹ̀ lọ́pọ̀lọpọ̀ wá sí Apple Reminders; gbígba ìṣẹ̀lẹ̀ sílẹ̀ sí Calendar; àti àwọn àṣẹ iṣẹ́, àkọsílẹ̀, iṣẹ́-àkànṣe, àti ìfojúsùn sí Alfred. AppleScript àti Automator ń jẹ́ kí àwọn ìṣàn-iṣẹ́ abínibí wà ní ìbámu pẹ̀kípẹ̀kí pẹ̀lú macOS. Àwọn ohun-ìbámu API ń lo Todoist API v1, Notion API 2026-03-11, Microsoft Graph v1.0, àti Google Keep v1. Àwọn ohun-ìbámu Things àti OmniFocus náà wà nínú rẹ̀. Àwọn ìdánwò tí a gbàlejò ń ṣàyẹ̀wò àwọn ohun-ìbámu API pẹ̀lú ètò ìdánwò HTTPS abẹ́lé; ìbámu ní àyíká gidi ṣì nílò àwọn àkọọ́lẹ̀ olùpèsè tí a yà sọ́tọ̀.

## Ohun tí o lè ṣe

- **Gba iṣẹ́ sílẹ̀ láìyí àpù padà.** Lo Automator Service, ọ̀rọ̀-kọ́kọ́rọ́ Alfred, tàbí pátákó ìdáàkọ láti fi iṣẹ́ kún un. Ìgbàsílẹ̀ lọ́pọ̀lọpọ̀ ń ṣẹ̀dá ìránnilétí kan fún ìlà kọ̀ọ̀kan tí kò ṣófo.
- **Sọ ọ̀rọ̀ di àwọn iṣẹ́ tí a ṣètò dáadáa.** Túpalẹ̀ àwọn déètì alábàátan àti ISO, àwọn àkókò, àwọn ipò ìṣáájú, àwọn àyíká, àti àwọn iṣẹ́-àkànṣe nípa lílo olùtúpalẹ̀ AppleScript ìṣiṣẹ́ tí ìgbàsílẹ̀ kíákíá abínibí àti ìgbàsílẹ̀ Calendar ń jọ lò.
- **Gba àwọn ìṣẹ̀lẹ̀ sílẹ̀ kí o sì ṣàyẹ̀wò àpótí ìwọlé rẹ.** Ṣẹ̀dá àwọn ìṣẹ̀lẹ̀ Calendar pẹ̀lú àkókò, gígùn-àkókò, àti ibi; ṣe àtúnyẹ̀wò ọ̀sọ̀ọ̀sẹ̀ onígbésẹ̀ márùn-ún pẹ̀lú ìdàjáde èrò sí inú Reminders.
- **Ṣiṣẹ́ ní àwọn ìgbà ìfojúsùn oníwọ̀n-àkókò.** Bẹ̀rẹ̀, ṣàyẹ̀wò, kí o sì dá àwọn ìgbà dúró káàkiri àwọn ìlànà ìṣiṣẹ́. Àwọn aago launchd tí ìgbà náà ni ń ṣàkóso ìparí àkókò àti ìfagilé; àwọn àkọsílẹ̀ JSONL ń pèsè ìtúpalẹ̀ gígùn-àkókò.
- **Lo Alfred fún ohun tí ó ju iṣẹ́ lọ.** Ṣẹ̀dá àwọn àtòjọ Reminders fún àwọn iṣẹ́-àkànṣe, fi àwọn àkọsílẹ̀ ìtọ́kasí pamọ́, ṣí àpótí ìwọlé fún àtúnyẹ̀wò, gba ọ̀rọ̀ pátákó ìdáàkọ sílẹ̀, kí o sì ṣàtúnṣe àwọn àṣàyàn tí ó ní irú dátà pàtó.
- **Wo àpótí ìwọlé rẹ láti ọ̀pá àtòjọ.** Àfikún SwiftBar/xbar tí ó jẹ́ àṣàyàn ń fi iye ohun àpótí ìwọlé tí kò tíì parí hàn ó sì ń so mọ́ àwọn ìṣàn-iṣẹ́ ìgbàsílẹ̀.

A ń ṣàyẹ̀wò ìṣesí abínibí lórí àwọn ẹ̀rọ Mac gidi tí GitHub gbàlejò: àwọn ìdánwò ń lo àwọn àpótí ìfọ̀rọ̀wérọ̀ Automator, lẹ́yìn náà wọ́n á ka àwọn àkọsílẹ̀ Reminders àti Calendar padà. Wo [ìdánwò àti ìbámu](#testing-and-compatibility) fún ààlà ẹ̀rí náà.

## Ìbẹ̀rẹ̀ kíákíá: Apple Reminders

```bash
git clone https://github.com/somethingwithproof/MacGTD.git
cd MacGTD
open workflows/apple/GTD-QuickCapture.workflow
```

Ṣí ìṣàn-iṣẹ́ náà nínú Automator kí o sì ṣiṣẹ́ rẹ̀ láti dán ìgbàsílẹ̀ wò. Láti jẹ́ kí ó wà ní àrọ́wọ́tó gẹ́gẹ́ bí Service, fi ìdìpọ̀ náà sí abẹ́ `~/Library/Services`:

```bash
mkdir -p ~/Library/Services
cp -R workflows/apple/GTD-QuickCapture.workflow ~/Library/Services/
```

Yan ọ̀nà-àbùjá kan ní **System Settings → Keyboard → Keyboard Shortcuts → Services**. Gba àyè Automation fún Reminders nígbà tí macOS bá béèrè. Tẹ èyí sí i:

```text
Buy groceries @errands +shopping !1 due:tomorrow
```

Ìṣàn-iṣẹ́ abínibí náà ń ṣẹ̀dá ìránnilétí onípò-ìṣáájú gíga tí ó yẹ ní ọ̀la, ó ń darí rẹ̀ sí àtòjọ `shopping`, ó sì ń kọ àyíká náà sílẹ̀. Láìsí àmì iṣẹ́-àkànṣe tàbí àyíká, ìgbàsílẹ̀ kíákíá ń lo `Inbox`.

## Ìlànà ìkọ̀wé ìgbàsílẹ̀

Olùtúpalẹ̀ iṣẹ́ abínibí àti ìgbàsílẹ̀ iṣẹ́ Alfred ń dá àwọn àmì wọ̀nyí mọ̀. Àwọn ohun-ìbámu olùpèsè ní àtìlẹ́yìn pápá àti ìdarí tiwọn.

| Ìtẹ̀wọlé | Ìtumọ̀ | Àpẹẹrẹ |
| --- | --- | --- |
| `!1`, `!2`, `!3` | Ipò ìṣáájú gíga, àárín, tàbí kékeré | `Fix login !1` |
| `today`, `tomorrow`, `next week` | Déètì ìparí alábàátan | `Call dentist tomorrow` |
| Ọjọ́ ọ̀sẹ̀ tàbí `next weekday` | Déètì ìparí ọjọ́ ọ̀sẹ̀ | `Send report next monday` |
| `due:YYYY-MM-DD` | Déètì ìparí pàtó | `Renew membership due:2027-03-15` |
| Àkókò lẹ́gbẹ̀ẹ́ déètì kan | Àkókò ìparí | `Call Alex tomorrow at 3pm` |
| `@context` | Àmì àyíká | `Buy milk @errands` |
| `+project` | Ìdarí iṣẹ́-àkànṣe/àtòjọ | `Draft outline +website` |

A tún ń gba `due:today` àti `due:tomorrow`. Lo àwọn lẹ́tà, nọ́ńbà, ìlà-abẹ́, tàbí àmì-ìdàpọ̀ nínú àwọn àmì àyíká àti iṣẹ́-àkànṣe. Ìgbàsílẹ̀ kíákíá abínibí ń fún ìdarí iṣẹ́-àkànṣe ní ipò ìṣáájú ju ìdarí àyíká lọ.

Ìgbàsílẹ̀ Calendar ń lo `@` fún ibi ìṣẹ̀lẹ̀ náà ó sì ń gba gígùn-àkókò ní ìṣẹ́jú tàbí wákàtí:

```text
Planning tomorrow 2pm 45m @Conference Room
```

Láìsí àkókò tàbí gígùn-àkókò pàtó, ìgbàsílẹ̀ Calendar ń lo 9:00 AM àti wákàtí kan, nínú kàlẹ́ńdà àkọ́kọ́ tí a lè kọ sí.

### Alfred

Ó nílò Alfred pẹ̀lú Powerpack. Kọ́ pákéèjì náà láti inú kòòdù orísun lọ́wọ́lọ́wọ́:

```bash
./scripts/package-alfred.sh
open dist/MacGTD.alfredworkflow
```

O tún lè gba pákéèjì náà sílẹ̀ láti [àwọn ìtújáde](https://github.com/somethingwithproof/MacGTD/releases). Àwọn pákéèjì ìtújáde ń fi kòòdù orísun tí a sàmì sí hàn; àwọn ẹ̀yà tí a fi kún `main` lẹ́yìn ìtújáde kan nílò ìkọ́lé láti inú orísun.

| Ọ̀rọ̀-kọ́kọ́rọ́ | Ìgbésẹ̀ |
| --- | --- |
| `task` | Gba iṣẹ́ kan sílẹ̀ pẹ̀lú ìtúpalẹ̀ déètì, àyíká, iṣẹ́-àkànṣe, àti ipò ìṣáájú |
| `note` | Fi àkọsílẹ̀ ìtọ́kasí pamọ́ sínú Reminders |
| `project` | Ṣẹ̀dá àtòjọ Reminders kan |
| `gtd process` | Ṣí Inbox fún àtúnyẹ̀wò ènìyàn |
| `clip` | Gba ọ̀rọ̀ pátákó ìdáàkọ sílẹ̀ |
| `gtd focus` | Bẹ̀rẹ̀ ìgbà ìfojúsùn kan, ṣàyẹ̀wò ipò rẹ̀, tàbí dá a dúró |
| `gtd analytics` | Ṣàyẹ̀wò àwọn gígùn-àkókò ìfojúsùn tí a kọ sílẹ̀ |
| `gtd preferences` | Ṣàtúnṣe àwọn àṣàyàn ìṣàn-iṣẹ́ |

```text
task Prepare slides tomorrow @work +presentation !2
gtd focus @work 25
gtd focus status
gtd focus stop
```

Àwọn àṣàyàn wà ní `~/Library/Preferences/com.alfredgtd.plist`; ipò ìfojúsùn àti àwọn àkọsílẹ̀ ìṣiṣẹ́ wà ní abẹ́ `~/.gtd`. Àwọn àṣàyàn ní àwọn ìyàn àkọ́bẹ̀rẹ̀ tí a kọ́ sínú rẹ̀, àyẹ̀wò irú dátà, àwọn ìgbéwọlé tí a fìdí múlẹ̀, àti ìkọsílẹ̀ aláìlèpín. Àwọn ìgbà ìfojúsùn kì í yí ètò ìfitónilétí ẹ̀rọ padà. Ṣíṣàkóso àpótí ìwọlé ń ṣí àtòjọ náà fún àtúnyẹ̀wò; kì í gbé tàbí parí àwọn iṣẹ́ fúnra rẹ̀.

Wo [ìtọ́sọ́nà Alfred](../../../workflows/alfred/README.md) àti [ìwé-àkọsílẹ̀ ilé-ìkàwé GTDLib](../../../workflows/alfred/GTDLib.scptd/README.md).

### Àwọn ohun-ìbámu ìgbàsílẹ̀ òde

Gbogbo àwọn ìṣàn-iṣẹ́ ìgbàsílẹ̀ API mẹ́rẹ̀ẹ̀rin ni a dán wò nípasẹ̀ àwọn àpótí ìfọ̀rọ̀wérọ̀ Automator gidi àti ètò ìdánwò TLS abẹ́lé nínú E2E tí a gbàlejò. Àkójọ ìdánwò ọwọ́ ọ̀tọ̀ọ̀tọ̀ ń dán ìfipamọ́ olùpèsè gidi wò nígbà tí a bá ṣètò àwọn àkọọ́lẹ̀ tí a yà sọ́tọ̀. Things àti OmniFocus nílò àkójọ ìdánwò ìṣọ̀kan ẹ̀rọ-tábìlì tí ó ní ìwé-àṣẹ.

| Àfojúsùn | Ọ̀nà ìṣiṣẹ́ | Ìṣètò / orísun |
| --- | --- | --- |
| Todoist | Ìgbàsílẹ̀ API | [Ìṣètò ìṣàn-iṣẹ́ àti Keychain](../../../workflows/todoist/) |
| Notion | Ìgbàsílẹ̀ API orísun dátà | [Ìṣètò ìṣàn-iṣẹ́ àti Keychain](../../../workflows/notion/) |
| Things 3 | Ìlànà URL | [Ìṣàn-iṣẹ́](../../../workflows/things/) |
| OmniFocus | AppleScript / Ìlànà URL | [Ìṣàn-iṣẹ́](../../../workflows/omnifocus/) |
| Microsoft To Do | Microsoft Graph v1.0 | [Ìṣàn-iṣẹ́](../../../workflows/microsoft/) |
| Google Keep | Workspace Keep API v1 | [Ìṣàn-iṣẹ́](../../../workflows/google/) |

Àwọn ohun-ìbámu API nílò ìṣètò ẹ̀rí ìdánimọ̀; Microsoft nílò ìfọwọ́sí OAuth aṣojú àti pé Google Keep nílò àyè Workspace tí ó yẹ:

```bash
./workflows/todoist/setup-todoist.sh
./workflows/notion/setup-notion.sh
./workflows/microsoft/setup-microsoft.sh
./workflows/google/setup-google.sh
```

Wo [ìṣètò API, ìṣíkiri, àti àwọn ohun tí ìfọwọ́sí nílò](../../../workflows/api/README.md). Àwọn ID ibi-ìpamọ́ dátà Notion tí ó ti wà tẹ́lẹ̀ ń ṣíkiri kìkì nígbà tí a bá rí orísun dátà kan ṣoṣo péré. Ìgbàsílẹ̀ Microsoft àti Google ń lo àwọn API dípò àwọn ọ̀nà-àbùjá aṣàwákiri tí kò ní àkọsílẹ̀. Àwọn tókìnì ìwọlé OAuth nílò ìsọdọ̀tun nípasẹ̀ oníbàárà OAuth rẹ. Àwọn ẹrù dátà ń lo àwọn kọ́kọ́rọ́ JSON pàtó, àwọn ìbéèrè HTTPS tí ó ní ààlà, àti ìjẹ́rìísí ìdáhùn. Àwọn ìfiránṣẹ́ àṣìṣe ń pa àlàyé ìkùnà mọ́ nígbà tí wọ́n ń bo tókìnì API tí a ṣètò mọ́lẹ̀. Wo [SECURITY.md](../../../SECURITY.md) fún fífi àwọn ìṣòro ààbò tó létí.

### Ọ̀pá àtòjọ àti Shortcuts

[Ìtọ́sọ́nà ọ̀pá àtòjọ](../../../workflows/menubar/README.md) ṣàlàyé nípa àfikún SwiftBar/xbar tí ó jẹ́ àṣàyàn. Fi àwọn Apple Services sórí ẹ̀rọ kọ́kọ́, lẹ́yìn náà ṣètò fódà àfikún nínú àpù ọ̀pá àtòjọ rẹ kí o sì so `workflows/menubar/gtd-menubar.sh` mọ́ inú rẹ̀.

[Ìtọ́sọ́nà Shortcuts](../../../workflows/shortcuts/README.md) ń pèsè ìṣètò ọwọ́ fún ìgbàsílẹ̀ ọ̀rọ̀, pátákó ìdáàkọ, àti Siri lórí macOS 12+. Shortcuts àti ìṣiṣẹ́ ohùn Siri wà níta àkójọ ìdánwò tí a gbàlejò.

## Ìgbékalẹ̀ ètò

Àwọn ìdìpọ̀ Automator ń fi AppleScript sínú ara wọn kí wọ́n lè ṣiṣẹ́ gẹ́gẹ́ bí Services abínibí. Alfred ń dì àwọn ìwé-àṣẹ ìgbésẹ̀ pọ̀ ó sì ń fi ìtẹ̀wọlé olùlò ránṣẹ́ gẹ́gẹ́ bí àwọn pàrámítà. GTDLib ń pèsè àwọn iṣẹ́ Reminders abínibí tí a ń pín lò láti inú orísun AppleScript tí a lè ṣàtúnṣe àti ìdìpọ̀ ìwé-àṣẹ tí a ti ṣàkójọpọ̀.

- **Olùtúpalẹ̀ ìṣiṣẹ́ kan ṣoṣo:** `scripts/sync-native-parser.py` ń fi olùtúpalẹ̀ tí a ń pín lò sínú Quick Capture àti Event Capture; ìfìdímúlẹ̀ ń ṣàwárí ìyàtọ̀ orísun.
- **Ipò ìfojúsùn tí ó dúró pẹ́:** àwọn ìpè ọ̀tọ̀ọ̀tọ̀ ń pín ipò ìgbà kan náà, pẹ̀lú àwọn iṣẹ́ launchd tí ìgbà náà ni àti ìṣirò àkókò tí ó ti kọjá tí ó ní ààlà.
- **Àwọn pákéèjì tí a lè tún ṣẹ̀dá bákan náà:** dídì pákéèjì ń kọ́ àkójọpọ̀ fáìlì tuntun, àwọn ìdánwò sì ń fi àkóónú rẹ̀ wé orísun. Ilé-ìkàwé náà ní ìwé-àṣẹ ìṣàkójọpọ̀ ọ̀tọ̀ọ̀tọ̀.
- **Àwọn ìdánwò tí a lè ṣàkíyèsí:** a ń pa àwọn ìròyìn JUnit, àwọn àkọsílẹ̀ àṣẹ, àti àwọn èso ìkọ́lé tí a dán wò mọ́ fún ọjọ́ 14 nínú GitHub Actions.

[Ìṣiṣẹ́ ìsọdọ̀tun API tí a fìdí múlẹ̀](https://github.com/somethingwithproof/MacGTD/actions/runs/37857977916) yege nínú **àwọn ìdánwò ìfìdímúlẹ̀ 35 lórí pẹpẹ ìfìdímúlẹ̀ kọ̀ọ̀kan àti àwọn ìdánwò E2E ẹ̀rọ-tábìlì 26**, láìsí ìkùnà, àṣìṣe, tàbí ìfòkọjá kankan. Ààlà ẹ̀rọ-tábìlì ní àwọn ìdánwò abínibí 15 àti àwọn ìdánwò ohun-ìbámu olùpèsè 11, pẹ̀lú àyẹ̀wò ìparí àkókò ìgbéjáde gidi àti àwọn àyẹ̀wò Keychain onígbà-díẹ̀. Ìfìdímúlẹ̀ tún ń ṣe àyẹ̀wò ìṣètò ibi-ìpamọ́ kòòdù. Àwọn èsì wọ̀nyí bo ìṣesí abínibí àti àwọn ètò ìdánwò olùpèsè; wọn kò fìdí ìbámu olùpèsè gidi tàbí àpù tí ó ní ìwé-àṣẹ múlẹ̀. Àwọn àmì-ẹ̀yẹ tí ó wà lókè ń fi ipò lọ́wọ́lọ́wọ́ hàn.

Àwọn ìbéèrè ìfàwọlé àti àwọn ìfiránṣẹ́ sí `main` ń ṣe ìfìdímúlẹ̀ kí E2E abínibí tó tẹ̀lé e. Ìṣàn-iṣẹ́ E2E tún ń ṣiṣẹ́ ní alálẹ́ àti lórí ìfiránṣẹ́ ọwọ́, pẹ̀lú àwọn ìdánwò ohun-ìbámu olùpèsè tí èsì wọn ṣeé sọ tẹ́lẹ̀. Àwọn ìdánwò olùpèsè gidi ń lo ìṣàn-iṣẹ́ ọwọ́ ọ̀tọ̀ọ̀tọ̀ `live-e2e.yml`. CI àkọ́bẹ̀rẹ̀ ń lo àwọn Mac tí GitHub gbàlejò tí a lè jù nù lẹ́yìn ìlò, àwọn ètò ìdánwò tí a yà sọ́tọ̀, àti àwọn ìlànà abẹ́ tí ó ní ààlà; kò sí olùṣiṣẹ́ tí a gbàlejò fúnra-ẹni tàbí ẹ̀rí ìdánimọ̀ àkọọ́lẹ̀ òde tí a nílò fún àkójọ àkọ́bẹ̀rẹ̀ náà. Àkójọ ìdánwò gidi ọwọ́ nílò àwọn àṣírí olùpèsè tí a yà sọ́tọ̀.

CI lọ́wọ́lọ́wọ́ kò fìdí àwọn ẹ̀yà macOS ìṣáájú múlẹ̀. Àwọn ìṣiṣẹ́ olùpèsè gidi nílò àwọn àṣírí tí a yà sọ́tọ̀, a kò sì tíì fìdí wọn múlẹ̀. Shortcuts/Siri àti àwọn àpù ẹ̀rọ-tábìlì tí ó ní ìwé-àṣẹ wà níta àkójọ tí a gbàlejò àkọ́bẹ̀rẹ̀. Àwọn ìdánwò ìgbésẹ̀ abínibí ń dán àwọn ìwé-àṣẹ Alfred tí a dì wò ní tààràtà; wọn kò fìdí ìbámu ojú-ìbánisọ̀rọ̀ Alfred kíkún múlẹ̀. Wo [ìṣètò ìdánwò, àwọn ohun tí a nílò ṣáájú, àti ààlà ìdánwò](../../../tests/e2e/README.md).

## Ìṣàbámu èdè àti agbègbè

Àwọn ọ̀rọ̀ CLI tí olùlò ń rí, olùṣiṣẹ́ ìdánwò, àti ọ̀pá àtòjọ wà ní èdè-agbègbè 45 (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) ní abẹ́ `locales/` nípasẹ̀ `scripts/i18n.py` láìsí ìgbẹ́kẹ̀lé ẹlẹ́kẹta kankan. Ìwádìí èdè-agbègbè ń ṣàyẹ̀wò `--lang`, lẹ́yìn náà `LC_ALL`, `LC_MESSAGES`, àti `LANG`, tí yóò sì padà sí `en` bí kò bá sí.

```bash
python3 scripts/i18n.py --lang de menubar.quick_capture
LANG=ja_JP.UTF-8 workflows/menubar/gtd-menubar.sh
```

## Ìdàgbàsókè

Fi [mise](https://mise.jdx.dev/) sórí ẹ̀rọ kí o sì lo ẹ̀yà Python tí a tọ́ka sí nínú `.mise.toml`:

```bash
mise install
mise exec -- python tests/run.py validation
./scripts/package-alfred.sh
./scripts/build-gtdlib.sh
```

Ìfìdímúlẹ̀ ń kọ àwọn ìròyìn sí abẹ́ `test-results/`; àwọn ìwé-àṣẹ ìkọ́lé ń kọ sí `dist/`. Láti ṣe àkójọ ìdánwò ẹ̀rọ-tábìlì tí a gbàlejò lórí `main`:

```bash
gh workflow run e2e.yml --ref main -f test_suite=automator
```

E2E ẹ̀rọ-tábìlì abẹ́lé nílò àkọọ́lẹ̀ ìdánwò tí a yà sọ́tọ̀ tí ó ti wọlé àti àwọn ìyọ̀nda tí a ṣàlàyé nínú [ìtọ́sọ́nà E2E](../../../tests/e2e/README.md). Ìwé-àṣẹ ìpèsè ìyọ̀nda tí a gbàlejò wà fún àwọn iṣẹ́ tí GitHub gbàlejò tí a lè jù nù lẹ́yìn ìlò nìkan.

Lo [Conventional Commits](https://www.conventionalcommits.org/) kí o sì tẹ̀lé [CONTRIBUTING.md](../../../CONTRIBUTING.md). Àwọn àyípadà tuntun wà ní àkọsílẹ̀ nínú [CHANGELOG.md](../../../CHANGELOG.md).

Àwọn ìṣàkóso ààbò, ìjẹ́rìísí ìfọwọ́sí ìtújáde, àti àwọn ààlà Scorecard tí ó kù wà ní àkọsílẹ̀ nínú [àyẹ̀wò ààbò](../../../docs/security-assessment.md).

pẹ̀lú ìtàn-orísun in-toto tí a fọwọ́ sí àti àwọn ìdìpọ̀ Sigstore tí a ṣàyẹ̀wò pẹ̀lú
