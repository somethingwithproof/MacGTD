**MacGTD என்பது நீங்கள் ஏற்கனவே பயன்படுத்தும் செயலிகளைக் கொண்டு பணிகளைப் பதிவு செய்யவும், நினைவூட்டல்களை ஒழுங்கமைக்கவும், நேரமிடப்பட்ட கவன அமர்வுகளை இயக்கவும் உதவும் macOS பணிப்பாய்வுகளின் தொகுப்பாகும்.**

[Getting Things Done](https://gettingthingsdone.com/) கட்டமைப்பை அடிப்படையாகக் கொண்டு உருவாக்கப்பட்ட இது, உரையாடல் பெட்டி, கிளிப்போர்டு மற்றும் தொகுப்புப் பதிவு வசதிகளை Apple Reminders க்கும்; நிகழ்வுப் பதிவை Calendar க்கும்; பணி, குறிப்பு, திட்டம் மற்றும் கவனக் கட்டளைகளை Alfred க்கும் கொண்டு வருகிறது. AppleScript மற்றும் Automator ஆகியவை இயல்புப் பணிப்பாய்வுகளை macOS உடன் நெருக்கமாக வைத்திருக்கின்றன. API ஏற்பிகள் Todoist API v1, Notion API 2026-03-11, Microsoft Graph v1.0 மற்றும் Google Keep v1 ஆகியவற்றைப் பயன்படுத்துகின்றன. Things மற்றும் OmniFocus ஏற்பிகளும் இதில் அடங்கும். ஹோஸ்ட் செய்யப்பட்ட சோதனைகள் ஒரு உள்ளூர் HTTPS சோதனைச் சூழலுக்கு எதிராக API ஏற்பிகளைச் சரிபார்க்கின்றன; நேரடி இணக்கத்தன்மைக்குத் தனிப்பட்ட வழங்குநர் கணக்குகள் இன்னும் தேவைப்படுகின்றன.

## நீங்கள் என்ன செய்யலாம்

- **செயலிகளை மாற்றாமலேயே பதிவு செய்யவும்.** ஒரு பணியைச் சேர்க்க Automator Service, Alfred முக்கியச்சொல் அல்லது கிளிப்போர்டைப் பயன்படுத்தவும். தொகுப்புப் பதிவு வெற்று அல்லாத ஒவ்வொரு வரிக்கும் ஒரு நினைவூட்டலை உருவாக்குகிறது.
- **உரையைக் கட்டமைக்கப்பட்ட பணிகளாக மாற்றவும்.** இயல்பு விரைவுப் பதிவு மற்றும் Calendar பதிவு ஆகிய இரண்டாலும் பகிரப்படும் தயாரிப்பு AppleScript பாகுபடுத்தியைப் பயன்படுத்தி, சார்பு மற்றும் ISO தேதிகள், நேரங்கள், முன்னுரிமைகள், சூழல்கள் மற்றும் திட்டங்களைப் பாகுபடுத்தவும்.
- **நிகழ்வுகளைப் பதிவு செய்து உங்கள் இன்பாக்ஸை மதிப்பாய்வு செய்யவும்.** நேரம், கால அளவு மற்றும் இடத்துடன் Calendar நிகழ்வுகளை உருவாக்கவும்; Reminders இல் எண்ணங்களைக் கொட்டி ஐந்து-படி வாராந்திர மதிப்பாய்வை இயக்கவும்.
- **நேரமிடப்பட்ட கவன அமர்வுகளில் பணியாற்றவும்.** செயல்முறைகளுக்கு இடையே அமர்வுகளைத் தொடங்கவும், ஆய்வு செய்யவும் மற்றும் நிறுத்தவும். அமர்வுக்குச் சொந்தமான launchd நேரங்காப்பான்கள் காலாவதி மற்றும் ரத்துசெய்தலைக் கையாளுகின்றன; JSONL பதிவுகள் கால அளவு பகுப்பாய்வுகளை வழங்குகின்றன.
- **பணிகளை விட அதிகமானவற்றிற்கு Alfred ஐப் பயன்படுத்தவும்.** திட்டங்களுக்கான Reminders பட்டியல்களை உருவாக்கவும், குறிப்புக் கட்டுரைகளைச் சேமிக்கவும், மதிப்பாய்வுக்காக இன்பாக்ஸைத் திறக்கவும், கிளிப்போர்டு உரையைப் பதிவு செய்யவும் மற்றும் வகைப்படுத்தப்பட்ட விருப்பத்தேர்வுகளைத் திருத்தவும்.
- **மெனு பட்டியில் உங்கள் இன்பாக்ஸைப் பார்க்கவும்.** விருப்பத்தேர்வு SwiftBar/xbar செருகுநிரல் முடிக்கப்படாத இன்பாக்ஸ் எண்ணிக்கையையும் பதிவுப் பணிப்பாய்வுகளுக்கான இணைப்புகளையும் காட்டுகிறது.

இயல்பு நடத்தை உண்மையான GitHub-hosted Mac கணினிகளில் சரிபார்க்கப்படுகிறது: சோதனைகள் Automator உரையாடல் பெட்டிகளை இயக்கி, பின்னர் Reminders மற்றும் Calendar பதிவுகளைத் திரும்பப் படிக்கின்றன. அந்த ஆதாரத்தின் நோக்கத்திற்கு [சோதனை மற்றும் இணக்கத்தன்மை](#testing-and-compatibility) பகுதியைப் பார்க்கவும்.

## விரைவுத் தொடக்கம்: Apple Reminders

```bash
git clone https://github.com/somethingwithproof/MacGTD.git
cd MacGTD
open workflows/apple/GTD-QuickCapture.workflow
```

பதிவு செய்வதை முயற்சிக்க Automator இல் பணிப்பாய்வைத் திறந்து இயக்கவும். அதை ஒரு Service ஆகக் கிடைக்கச் செய்ய, தொகுப்பை `~/Library/Services` கீழ் நிறுவவும்:

```bash
mkdir -p ~/Library/Services
cp -R workflows/apple/GTD-QuickCapture.workflow ~/Library/Services/
```

**System Settings → Keyboard → Keyboard Shortcuts → Services** என்பதில் ஒரு குறுக்குவழியை ஒதுக்கவும். macOS கேட்கும்போது Reminders க்கான Automation அணுகலை அனுமதிக்கவும். உள்ளிடவும்:

```text
Buy groceries @errands +shopping !1 due:tomorrow
```

இயல்புப் பணிப்பாய்வு நாளைக்குரிய உயர் முன்னுரிமை நினைவூட்டலை உருவாக்கி, அதை `shopping` பட்டியலுக்கு வழிநடத்தி, சூழலைப் பதிவு செய்கிறது. திட்டம் அல்லது சூழல் குறிப்பான் இல்லாவிட்டால், விரைவுப் பதிவு `Inbox` ஐப் பயன்படுத்துகிறது.

## பதிவுத் தொடரியல்

இயல்புப் பணிப் பாகுபடுத்தி மற்றும் Alfred பணிப் பதிவு ஆகியவை இந்தக் குறிப்பான்களை அடையாளம் காண்கின்றன. வழங்குநர் ஏற்பிகள் தமக்கெனத் தனிப்பட்ட புல மற்றும் வழிநடத்தல் ஆதரவைக் கொண்டுள்ளன.

| உள்ளீடு | பொருள் | எடுத்துக்காட்டு |
| --- | --- | --- |
| `!1`, `!2`, `!3` | உயர், நடுத்தர அல்லது குறைந்த முன்னுரிமை | `Fix login !1` |
| `today`, `tomorrow`, `next week` | சார்பு இறுதித் தேதி | `Call dentist tomorrow` |
| வார நாள் அல்லது `next weekday` | வார நாள் இறுதித் தேதி | `Send report next monday` |
| `due:YYYY-MM-DD` | வெளிப்படையான இறுதித் தேதி | `Renew membership due:2027-03-15` |
| தேதியுடன் கூடிய நேரம் | இறுதி நேரம் | `Call Alex tomorrow at 3pm` |
| `@context` | சூழல் குறிப்பான் | `Buy milk @errands` |
| `+project` | திட்டம்/பட்டியல் வழிநடத்தல் | `Draft outline +website` |

`due:today` மற்றும் `due:tomorrow` ஆகியவையும் ஏற்றுக்கொள்ளப்படுகின்றன. சூழல் மற்றும் திட்டக் குறிப்பான்களில் எழுத்துக்கள், எண்கள், அடிக்கோடுகள் அல்லது இடைக்கோடுகளைப் பயன்படுத்தவும். இயல்பு விரைவுப் பதிவு சூழல் வழிநடத்தலை விட திட்ட வழிநடத்தலுக்கு முன்னுரிமை அளிக்கிறது.

Calendar பதிவு நிகழ்வின் இடத்திற்கு `@` ஐப் பயன்படுத்துகிறது மற்றும் நிமிடங்கள் அல்லது மணிநேரங்களில் கால அளவை ஏற்றுக்கொள்கிறது:

```text
Planning tomorrow 2pm 45m @Conference Room
```

வெளிப்படையான நேரம் அல்லது கால அளவு இல்லாவிட்டால், Calendar பதிவு முதல் எழுதக்கூடிய நாள்காட்டியில் காலை 9:00 மணி மற்றும் ஒரு மணி நேரத்தைப் பயன்படுத்துகிறது.

### Alfred

Powerpack உடன் கூடிய Alfred தேவை. தற்போதைய மூலக் குறியீட்டிலிருந்து தொகுப்பை உருவாக்கவும்:

```bash
./scripts/package-alfred.sh
open dist/MacGTD.alfredworkflow
```

நீங்கள் [வெளியீடுகள்](https://github.com/somethingwithproof/MacGTD/releases) பக்கத்திலிருந்தும் தொகுப்பைப் பதிவிறக்கலாம். வெளியீட்டுத் தொகுப்புகள் அவற்றின் குறியிடப்பட்ட மூலக் குறியீட்டைப் பிரதிபலிக்கின்றன; ஒரு வெளியீட்டிற்குப் பிறகு `main` இல் சேர்க்கப்பட்ட அம்சங்களுக்கு மூலக் குறியீட்டு உருவாக்கம் தேவை.

| முக்கியச்சொல் | செயல் |
| --- | --- |
| `task` | தேதி, சூழல், திட்டம் மற்றும் முன்னுரிமைப் பாகுபடுத்தலுடன் பணியைப் பதிவு செய்தல் |
| `note` | Reminders இல் ஒரு குறிப்புத் தகவலைச் சேமித்தல் |
| `project` | Reminders பட்டியலை உருவாக்குதல் |
| `gtd process` | மனித மதிப்பாய்வுக்காக Inbox ஐத் திறத்தல் |
| `clip` | கிளிப்போர்டு உரையைப் பதிவு செய்தல் |
| `gtd focus` | கவன அமர்வைத் தொடங்குதல், நிலையை ஆய்வு செய்தல் அல்லது நிறுத்துதல் |
| `gtd analytics` | பதிவு செய்யப்பட்ட கவன கால அளவுகளை ஆய்வு செய்தல் |
| `gtd preferences` | பணிப்பாய்வு விருப்பத்தேர்வுகளைத் திருத்துதல் |

```text
task Prepare slides tomorrow @work +presentation !2
gtd focus @work 25
gtd focus status
gtd focus stop
```

விருப்பத்தேர்வுகள் `~/Library/Preferences/com.alfredgtd.plist` இலும், கவன நிலை மற்றும் பதிவுகள் `~/.gtd` கீழும் இருக்கும். விருப்பத்தேர்வுகளில் உள்ளமைக்கப்பட்ட இயல்புநிலைகள், வகைச் சரிபார்ப்புகள், சரிபார்க்கப்பட்ட இறக்குமதிகள் மற்றும் அணுநிலை எழுதுதல்கள் உள்ளன. கவன அமர்வுகள் கணினி அறிவிப்பு அமைப்புகளை மாற்றாது. Inbox செயலாக்கம் மதிப்பாய்வுக்காகப் பட்டியலைத் திறக்கும்; அது பணிகளைத் தானாக நகர்த்தவோ முடிக்கவோ செய்யாது.

[Alfred வழிகாட்டி](../../../workflows/alfred/README.md) மற்றும் [GTDLib நூலக ஆவணங்கள்](../../../workflows/alfred/GTDLib.scptd/README.md) ஆகியவற்றைப் பார்க்கவும்.

### வெளிப்புறப் பதிவு ஏற்பிகள்

நான்கு API பதிவுப் பணிப்பாய்வுகளும் ஹோஸ்ட் செய்யப்பட்ட E2E இல் உண்மையான Automator உரையாடல் பெட்டிகள் மற்றும் உள்ளூர் TLS சோதனைச் சூழல் மூலம் சோதிக்கப்படுகின்றன. பிரத்யேக கணக்குகள் கட்டமைக்கப்படும்போது ஒரு தனி கைமுறைச் சோதனைத் தொகுப்பு உண்மையான வழங்குநர் நிலைத்தன்மையைச் சோதிக்கிறது. Things மற்றும் OmniFocus ஆகியவற்றுக்கு உரிமம் பெற்ற டெஸ்க்டாப் ஒருங்கிணைப்புத் தொகுப்பு தேவை.

| இலக்கு | செயல்முறை | அமைப்பு / மூலம் |
| --- | --- | --- |
| Todoist | API பதிவு | [பணிப்பாய்வு மற்றும் Keychain அமைப்பு](../../../workflows/todoist/) |
| Notion | தரவு மூல API பதிவு | [பணிப்பாய்வு மற்றும் Keychain அமைப்பு](../../../workflows/notion/) |
| Things 3 | URL திட்டம் | [பணிப்பாய்வு](../../../workflows/things/) |
| OmniFocus | AppleScript / URL திட்டம் | [பணிப்பாய்வு](../../../workflows/omnifocus/) |
| Microsoft To Do | Microsoft Graph v1.0 | [பணிப்பாய்வு](../../../workflows/microsoft/) |
| Google Keep | Workspace Keep API v1 | [பணிப்பாய்வு](../../../workflows/google/) |

API ஏற்பிகளுக்கு நற்சான்றிதழ் அமைப்பு தேவை; Microsoft க்குப் பிரதிநிதித்துவப்படுத்தப்பட்ட OAuth அங்கீகாரமும் Google Keep க்குத் தகுதியான Workspace அணுகலும் தேவை:

```bash
./workflows/todoist/setup-todoist.sh
./workflows/notion/setup-notion.sh
./workflows/microsoft/setup-microsoft.sh
./workflows/google/setup-google.sh
```

[API அமைப்பு, இடம்பெயர்வு மற்றும் அங்கீகாரத் தேவைகள்](../../../workflows/api/README.md) என்பதைப் பார்க்கவும். சரியாக ஒரு தரவு மூலம் கண்டறியப்படும்போது மட்டுமே ஏற்கனவே உள்ள Notion தரவுத்தள IDகள் இடம்பெயரும். Microsoft மற்றும் Google பதிவு ஆகியவை ஆவணப்படுத்தப்படாத உலாவி குறுக்குவழிகளுக்குப் பதிலாக APIகளைப் பயன்படுத்துகின்றன. OAuth அணுகல் டோக்கன்களுக்கு உங்கள் OAuth கிளையண்ட் வழியாகப் புதுப்பித்தல் தேவை. பேலோடுகள் வெளிப்படையான JSON விசைகள், வரம்பிடப்பட்ட HTTPS கோரிக்கைகள் மற்றும் மறுமொழி உறுதிப்படுத்தலைப் பயன்படுத்துகின்றன. பிழைச் செய்திகள் கட்டமைக்கப்பட்ட API டோக்கனை மறைத்தவாறு தோல்வி விவரங்களைத் தக்கவைக்கின்றன. பாதுகாப்புச் சிக்கல்களைப் புகாரளிக்க [SECURITY.md](../../../SECURITY.md) ஐப் பார்க்கவும்.

### மெனு பட்டி மற்றும் Shortcuts

[மெனு பட்டி வழிகாட்டி](../../../workflows/menubar/README.md) விருப்பத்தேர்வு SwiftBar/xbar செருகுநிரலை உள்ளடக்கியது. முதலில் Apple Services ஐ நிறுவி, பின்னர் உங்கள் மெனு பட்டி செயலியில் செருகுநிரல் கோப்பகத்தைக் கட்டமைத்து, அதில் `workflows/menubar/gtd-menubar.sh` ஐ இணைக்கவும்.

[Shortcuts வழிகாட்டி](../../../workflows/shortcuts/README.md) macOS 12+ இல் உரை, கிளிப்போர்டு மற்றும் Siri பதிவுக்கான கைமுறை அமைப்பை வழங்குகிறது. Shortcuts மற்றும் Siri குரல் செயல்பாடு ஆகியவை ஹோஸ்ட் செய்யப்பட்ட சோதனைத் தொகுப்பிற்கு வெளியே உள்ளன.

## கட்டமைப்பு

Automator தொகுப்புகள் இயல்பு Services ஆக இயங்கும் வகையில் AppleScript ஐ உட்பொதிக்கின்றன. Alfred செயல் ஸ்கிரிப்டுகளைத் தொகுத்து பயனர் உள்ளீட்டை அளவுருக்களாக அனுப்புகிறது. GTDLib திருத்தக்கூடிய AppleScript மூலம் மற்றும் தொகுக்கப்பட்ட ஸ்கிரிப்ட் தொகுப்பிலிருந்து பகிரப்பட்ட இயல்பு Reminders செயல்பாடுகளை வெளிப்படுத்துகிறது.

- **ஒரு தயாரிப்பு பாகுபடுத்தி:** `scripts/sync-native-parser.py` பகிரப்பட்ட பாகுபடுத்தியை Quick Capture மற்றும் Event Capture இல் உட்பொதிக்கிறது; சரிபார்ப்பு மூலக் குறியீட்டு விலகலைக் கண்டறிகிறது.
- **நிலைத்திருக்கும் கவன நிலை:** தனித்தனி அழைப்புகள் சொந்த launchd பணிகள் மற்றும் வரம்பிடப்பட்ட கழிந்த நேரக் கணக்கீட்டுடன் அமர்வு நிலையைப் பகிர்ந்து கொள்கின்றன.
- **மீண்டும் உருவாக்கக்கூடிய தொகுப்புகள்:** தொகுப்பாக்கம் ஒரு புதிய காப்பகத்தை உருவாக்குகிறது, மேலும் சோதனைகள் அதன் உள்ளடக்கங்களை மூலக் குறியீட்டுடன் ஒப்பிடுகின்றன. நூலகத்திற்குத் தனித் தொகுப்பு ஸ்கிரிப்ட் உள்ளது.
- **கவனிக்கத்தக்க சோதனைகள்:** JUnit அறிக்கைகள், கட்டளைப் பதிவுகள் மற்றும் சோதிக்கப்பட்ட உருவாக்கக் கூறுகள் GitHub Actions இல் 14 நாட்களுக்குத் தக்கவைக்கப்படுகின்றன.

[சரிபார்க்கப்பட்ட API நவீனமயமாக்கல் இயக்கம்](https://github.com/somethingwithproof/MacGTD/actions/runs/37857977916) **ஒவ்வொரு சரிபார்ப்புத் தளத்திலும் 35 சரிபார்ப்புச் சோதனைகளிலும் 26 டெஸ்க்டாப் E2E சோதனைகளிலும்** எந்தத் தோல்விகளும், பிழைகளும் அல்லது தவிர்ப்புகளும் இன்றித் தேர்ச்சி பெற்றது. டெஸ்க்டாப் சோதனையில் உண்மையான போக்குவரத்து நேர முடிவும் நிலையற்ற Keychain சோதனைகளும் உட்பட 15 இயல்புச் சோதனைகள் மற்றும் 11 வழங்குநர் ஏற்பி சோதனைகள் அடங்கும். சரிபார்ப்பு களஞ்சியக் கட்டமைப்புச் சோதனைகளையும் இயக்குகிறது. இந்த முடிவுகள் இயல்பு நடத்தை மற்றும் வழங்குநர் சோதனைச் சூழல்களை உள்ளடக்கியவை; அவை நேரடி வழங்குநர் அல்லது உரிமம் பெற்ற செயலி இணக்கத்தன்மையை நிறுவவில்லை. தற்போதைய நிலை மேலே உள்ள பேட்ஜ்களால் காட்டப்படுகிறது.

புல் கோரிக்கைகள் மற்றும் `main` க்குத் தள்ளுதல் ஆகியவை சரிபார்ப்பையும் அதைத் தொடர்ந்து இயல்பு E2E ஐயும் இயக்குகின்றன. E2E பணிப்பாய்வு இரவிலும் கைமுறை இயக்கத்திலும் இயங்குகிறது, இதில் உறுதியான வழங்குநர் ஏற்பி சோதனைகளும் அடங்கும். நேரடி வழங்குநர் சோதனைகள் தனி கைமுறை `live-e2e.yml` பணிப்பாய்வைப் பயன்படுத்துகின்றன. இயல்புநிலை CI ஒருமுறை பயன்படுத்தக்கூடிய GitHub-hosted Mac கணினிகள், தனிமைப்படுத்தப்பட்ட சோதனைச் சூழல்கள் மற்றும் வரம்பிடப்பட்ட துணைச்செயல்முறைகளைப் பயன்படுத்துகிறது; இயல்புநிலைத் தொகுப்புக்குச் சுய-ஹோஸ்ட் செய்யப்பட்ட ரன்னர் அல்லது வெளிப்புறக் கணக்கு நற்சான்றிதழ்கள் தேவையில்லை. கைமுறை நேரடித் தொகுப்புக்குப் பிரத்யேக வழங்குநர் ரகசியங்கள் தேவை.

முந்தைய macOS பதிப்புகள் தற்போதைய CI ஆல் சரிபார்க்கப்படவில்லை. நேரடி வழங்குநர் இயக்கங்களுக்குப் பிரத்யேக ரகசியங்கள் தேவை மற்றும் அவை இன்னும் சரிபார்க்கப்படவில்லை. Shortcuts/Siri மற்றும் உரிமம் பெற்ற டெஸ்க்டாப் செயலிகள் இயல்புநிலை ஹோஸ்ட் செய்யப்பட்ட தொகுப்பிற்கு வெளியே உள்ளன. இயல்புச் செயல் சோதனைகள் தொகுக்கப்பட்ட Alfred ஸ்கிரிப்டுகளை நேரடியாகச் சோதிக்கின்றன; அவை முழு Alfred UI இணக்கத்தன்மையை நிறுவவில்லை. [சோதனை அமைப்பு, முன்நிபந்தனைகள் மற்றும் உள்ளடக்கம்](../../../tests/e2e/README.md) என்பதைப் பார்க்கவும்.

## உள்ளூர்மயமாக்கல்

பயனர்-எதிர்கொள்ளும் CLI, சோதனை ரன்னர் மற்றும் மெனு பட்டி சரங்கள் 45 மொழிகளில் (`en`, `de`, `es`, `fr`, `it`, `pt-BR`, `nl`, `ru`, `uk`, `ja`, `ko`, `zh-CN`, `zh-TW`, `ar`, `hi`, `pl`, `tr`, `sv`, `vi`, `id`, `af-ZA`, `am-ET`, `ar-EG`, `ar-MA`, `fr-MA`, `fr-SN`, `ha-NG`, `ig-NG`, `mg-MG`, `rw-RW`, `so-SO`, `sw-KE`, `xh-ZA`, `yo-NG`, `zu-ZA`, `bn`, `fa`, `he`, `mr`, `ta`, `te`, `th`, `ur`, `ms`, `fil`) `locales/` கீழ் `scripts/i18n.py` வழியாக எந்த மூன்றாம் தரப்புச் சார்புகளும் இன்றி வழங்கப்படுகின்றன. உள்ளூர்மயமாக்கல் தீர்வு `--lang`, பின்னர் `LC_ALL`, `LC_MESSAGES` மற்றும் `LANG` ஆகியவற்றைச் சரிபார்த்து, இறுதியில் `en` க்குத் திரும்புகிறது.

```bash
python3 scripts/i18n.py --lang de menubar.quick_capture
LANG=ja_JP.UTF-8 workflows/menubar/gtd-menubar.sh
```

## மேம்பாடு

[mise](https://mise.jdx.dev/) ஐ நிறுவி, `.mise.toml` இல் பொருத்தப்பட்டுள்ள Python பதிப்பைப் பயன்படுத்தவும்:

```bash
mise install
mise exec -- python tests/run.py validation
./scripts/package-alfred.sh
./scripts/build-gtdlib.sh
```

சரிபார்ப்பு `test-results/` கீழ் அறிக்கைகளை எழுதுகிறது; உருவாக்க ஸ்கிரிப்டுகள் `dist/` இல் எழுதுகின்றன. `main` இல் ஹோஸ்ட் செய்யப்பட்ட டெஸ்க்டாப் தொகுப்பை இயக்க:

```bash
gh workflow run e2e.yml --ref main -f test_suite=automator
```

உள்ளூர் டெஸ்க்டாப் E2E க்குப் பிரத்யேக உள்நுழைந்த சோதனைக் கணக்கு மற்றும் [E2E வழிகாட்டி](../../../tests/e2e/README.md) இல் விவரிக்கப்பட்டுள்ள அனுமதிகள் தேவை. ஹோஸ்ட் செய்யப்பட்ட அனுமதி வழங்கல் ஸ்கிரிப்ட் ஒருமுறை பயன்படுத்தக்கூடிய GitHub-hosted பணிகளுக்கு மட்டுமே கட்டுப்படுத்தப்பட்டுள்ளது.

[Conventional Commits](https://www.conventionalcommits.org/) ஐப் பயன்படுத்தி [CONTRIBUTING.md](../../../CONTRIBUTING.md) ஐப் பின்பற்றவும். சமீபத்திய மாற்றங்கள் [CHANGELOG.md](../../../CHANGELOG.md) இல் பதிவு செய்யப்பட்டுள்ளன.

பாதுகாப்புக் கட்டுப்பாடுகள், வெளியீட்டுக் கையொப்பச் சரிபார்ப்பு மற்றும் மீதமுள்ள Scorecard
வரம்புகள் ஆகியவை [பாதுகாப்பு மதிப்பீட்டில்](../../../docs/security-assessment.md) ஆவணப்படுத்தப்பட்டுள்ளன.
வெளியீட்டுப் பணிப்பாய்வு வரைவு வெளியீட்டை உருவாக்குவதற்கு முன் தொகுப்புகளை உருவாக்கிச் சான்றளிக்கிறது,
இதில் மூலக் கமிட் மற்றும் ref க்கு எதிராகச் சரிபார்க்கப்பட்ட கையொப்பமிடப்பட்ட in-toto provenance மற்றும் Sigstore தொகுப்புகள் அடங்கும்.
புதிய provenance அந்தப் பணிப்பாய்வு உருவாக்கங்களுக்குப் பொருந்தும், பழைய பதிவிறக்கங்களுக்கு அல்ல.
